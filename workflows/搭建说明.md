# 两个工作流怎么搭建

这两份 starter JSON 是按官方节点接口准备的起步图，未在你的 Comfy Cloud 账号运行验证。云端可用节点、模型和额度需在账号内确认。文件名含 starter，避免误认为已经跑通。

## 先跑主体抠图

打开 https://cloud.comfy.org ，新建工作流，双击画布搜索以下节点并连接：

```text
Load Image 的 IMAGE
  → Recraft Remove Background 的 image
  → Save Image 的 images（连接抠图节点的 IMAGE 输出）
```

在 Load Image 上传一张人物照片，点击 Run。Recraft 是收费合作伙伴节点。保存一张 PNG，检查人物完整、头发边缘没有严重缺失、背景透明。棋盘格预览不是最终证据，可把 PNG 放在彩色底上检查。

当前官方 Recraft 输出 RGBA IMAGE，直接接 SaveImage 即可保留透明度；不要在保存前经由剥离 Alpha 的节点。若云端版本节点未输出 RGBA，应先检查实际 IMAGE/MASK 行为，不要随意把 MASK 接 JoinImageWithAlpha：不同节点的蒙版方向可能相反。

项目提供 `cutout-api.starter.json`。如果云端编辑器支持导入 API 图，可直接尝试导入并替换测试输入；不支持时，按上面的三个节点手动搭建。实际导出后的节点 ID 可能不同。

## 再搭基础融合

此版本用已合成人物的图片作为图生图输入，不含独立身份编码器。低去噪有助于减少样貌和服装改变，但不能保证人物一致性。先验证流程，再按实测结果增加身份参考或适合人物保真的图像编辑分支。

添加以下节点：

1. Checkpoint Loader（CheckpointLoaderSimple）：选择账号内可用的普通 SDXL 模型；不要把 FLUX、SD3 或其他架构的模型直接代入本图。
2. Load Image：加载一张已经把人物放进背景的测试合成图。
3. 第二个 Load Image：加载同尺寸 RGB 蒙版，人物白、背景黑；其 IMAGE 输出接 ImageToMask，channel 选 red。
4. VAE Encode：pixels 接合成图，vae 接 Checkpoint Loader 的 VAE。
5. Set Latent Noise Mask：samples 接 VAE Encode，mask 接 ImageToMask。
6. 两个 CLIP Text Encode：clip 都接模型的 CLIP，分别填写正向和负向提示词。
7. KSampler：model 接模型 MODEL，positive/negative 接两个提示词节点，latent_image 接 Set Latent Noise Mask。
8. VAE Decode：samples 接 KSampler，vae 接模型 VAE。
9. Get Image Size：读取输入合成图尺寸。
10. Upscale Image（ImageScale）：image 接 VAE Decode，width/height 转为输入后分别接 Get Image Size 的宽/高，crop 设 disabled，upscale_method 设 lanczos。用于恢复非 8 倍数输入的原始尺寸。
11. Save Image：接 ImageScale。

起步参数：denoise=0.18、steps=24、cfg=5、sampler=dpmpp_2m、scheduler=karras。它们是实验起点，不是保真效果保证。先用第一张 736×736 背景验证，再测试竖幅。

`fusion-api.starter.json` 的 checkpoint 名是明显占位符，必须替换成云端实际模型名。测试合成图与蒙版也需要替换。原人物参考绑定留空：这份基础图没有该分支，填写一个加载节点并不会自动产生身份约束。

测试正向提示词示例：

> Preserve the person's facial features, hairstyle, clothing colors and garment details. Match warm natural lighting and the illustrated scene, softly blend edges. Keep the person in the same position and pose.

Run 后确认只有一张最终结果、位置正常、脸和衣物没有明显变化、尺寸与输入一致。

## 导出并接回网站

在云端工作流菜单找 API 格式导出（可能显示 Export API 或 Save API Format；若入口隐藏，检查设置中的开发者选项）。判断文件格式：顶层是节点 ID，节点包含 `class_type`、`inputs`；顶层若是 `nodes`、`links` 数组，则是编辑器画布格式，不能直接填入网站 API 工作流栏。

以项目 starter 的 ID 为例：

| 网站字段 | 填写值 |
|---|---|
| 抠图人物输入 | `1.image` |
| 抠图输出节点 | `3` |
| 融合合成图输入 | `2.image` |
| 融合蒙版输入 | `3.image` |
| 融合原人物参考 | 留空（基础图没有独立参考分支） |
| 融合去噪强度 | `9.denoise` |
| 融合正向提示词 | `7.text` |
| 融合输出节点 | `13` |

自己在画布上创建后，应按照实际导出的 ID 填写，而不是照搬表中数字。
