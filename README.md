# 入景 · Scene Studio

人像拍摄与报刊封面合成网站。当前唯一模板为「粤美海幢 · 古寺新潮」，旧街景模板已移除；主页不显示模板选择或报刊位置预览，生成成功后才显示结果图片，拍摄界面保留左右切换和相机翻转，方便以后继续增加模板。

## 人像生成

上传和相机采用相同流程：提取单个透明人物图层 → 根据 Alpha 边界等比定位 → 多图参考融合 → 还原照片区外的原始版面。融合请求只发送主照片区的初步合成、用户原照和主照片区的原背景。模型按真实现场摄影匹配光线与人物边缘，浏览器将结果贴回原报纸，保留照片区外的原始像素。

首次成功生成包含抠图与融合两次收费调用，不自动重试；同照片可复用抠图。快速模式使用 1K 抠图，精细模式使用 2K 抠图。融合尺寸按各模板的主照片区比例计算，下载为原模板尺寸的 PNG。AI 人物保真与构图需实际检查；原片不足的细节由模型推断。

输入支持 PNG/JPEG/WebP；HEIC/HEIF 取决于浏览器解码能力。前端缩放至最长边1600，非透明照片转 JPEG，透明图保留 PNG。相机默认后摄，不请求固定视频尺寸、比例或 crop-and-scale；前摄镜像仅用于取景，拍摄保存完整原始视频帧。系统相机内不显示网页模板。

## 凭证与部署

### Render

将项目源码推到 Render 可访问的 Git 仓库，然后在 Render 控制台选择 **New → Blueprint**，连接仓库并使用根目录的 `render.yaml`。在部署时提示的环境变量表单中填写 `ARK_API_KEY`。如需使用自定义图片模型或接入点，在 Render 的 **Environment** 页面设置 `ARK_IMAGE_MODEL`。不要提交 `.env` 或把密钥填进 Blueprint 文件。

Render 使用服务的 HTTPS 地址提供首页和 API。访客共用服务端方舟凭证，生成请求消耗该账号额度。每个浏览器只能读取自己发起的生成任务。服务一次处理一个任务，结果临时保存在内存中，服务重启后需重新生成。Blueprint 默认选择 Free 实例。

### 现有 Netlify 部署

本地密钥仅在后端内存保存，或由用户写入忽略的 .env；模型 ID 单独保存至 .runtime/ark.json。公网使用 Netlify Functions、Background Functions 和私有 Blobs，密钥通过加密 HttpOnly Cookie 隔离到当前浏览器，有效期24小时；若 Netlify 配置了服务端 ARK_API_KEY，则访客可直接生成。可选 ARK_IMAGE_MODEL 指定共享模型，两项均设置在 Functions 作用域，修改后重新部署。访客也可以在设置中使用自己的凭证。任务结束删除临时输入，结果保留1小时，请及时下载。

部署原站点：npx netlify deploy --prod --dir public --functions netlify/functions 。保留原站点私有会话存储。.netlify/、.runtime/、node_modules/、.env 均已忽略，浏览器 QA 文件不发布。
